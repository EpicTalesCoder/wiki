Git là hệ thống quản lý phiên bản phổ biến nhất hiện nay. Bài viết này sẽ hướng dẫn các lệnh cơ bản.

## Khởi tạo repository

```bash
git init
git add .
git commit -m "Initial commit"
```

## Clone repository

```bash
git clone https://github.com/user/repo.git
```

## Branch và Merge

```bash
git checkout -b feature/new-feature
git add .
git commit -m "Add new feature"
git checkout main
git merge feature/new-feature
```
