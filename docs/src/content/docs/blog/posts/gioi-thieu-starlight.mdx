Starlight là một framework documentation được xây dựng trên Astro. Nó cung cấp các tính năng sẵn có giúp xây dựng trang tài liệu nhanh chóng.

## Tính năng chính

- Tìm kiếm nội bộ
- Internationalization (i18n)
- Theme tùy chỉnh
- Sidebar tự động
- SEO optimization
